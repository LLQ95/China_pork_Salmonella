# Reproducible provincial ecological analysis

This directory contains the code and data needed to reproduce the
province-level ecological analysis reported in the manuscript on 1,402
non-typhoidal Salmonella enterica isolates recovered from retail pork
across 25 Chinese provinces, autonomous regions, and municipalities in
2021.

## Contents

```
.
|-- provincial_ecological_analysis.R   # Main analysis script
|-- figure6_resistance.R               # Figure 6 plotting script
|-- README.md
|-- data
|   |-- province_level_data.csv        # 25 provinces, 17 candidate factors
|   |-- isolate_level_data.csv         # 1,402 isolates with group labels
|   `-- ast_19_drugs.csv               # 19-drug binary calls and S/I/R labels
`-- outputs                             # Tables and figures generated by the scripts
```

`province_level_data.csv` contains one row per province. The response is
the province-level mean number of antimicrobial resistance genes (ARGs),
and the 17 candidate variables cover climate, agricultural production,
pollution, and socioeconomic indicators. `isolate_level_data.csv`
contains one row per isolate, with the serovar, sequence type,
temperature group, income group, ARG count, IncFIB(K) carriage, and the
legacy phenotype columns. `ast_19_drugs.csv` holds the 19 tested drugs
for every isolate as a binary resistant indicator and as the original
susceptible, intermediate, or resistant category.

## How to run

Both scripts use relative paths and should be run from this directory:

```sh
Rscript provincial_ecological_analysis.R
Rscript figure6_resistance.R
```

The main script requires `glmnet`, `car`, `mgcv`, `dplyr`, `sandwich`,
and `lmtest`. The figure script requires `ggplot2`, `tidyr`, and
`patchwork`. They were developed and tested with R 4.6.0:

```r
install.packages(c("glmnet", "car", "mgcv", "dplyr", "sandwich",
                   "lmtest", "ggplot2", "tidyr", "patchwork"))
```

A fixed seed is set at the start of the main script, and cross-validation
fold identifiers are assigned explicitly, so repeated runs produce
identical results.

## Analysis steps

The main script follows the order of the statistical methods described in
the manuscript. It first calculates Spearman rank correlations between
each candidate factor and provincial ARG abundance. The factors showing a
significant positive bivariate association enter the full-data LASSO
stage, where the penalty is chosen with five-fold cross-validation.

Variable stability is assessed with a nested leave-one-out
cross-validation. When each province is held out in turn, the Spearman
screening, standardization, and inner five-fold penalty tuning are all
repeated on the training folds only, so the held-out province takes no
part in any modeling decision. The loop records how often every
candidate is retained. The final parsimonious model is an ordinary linear
model with temperature and GDP per capita, and the script reports
coefficients, 95% confidence intervals, p values, R-squared, adjusted
R-squared, AIC, and the overall model p value.

Multicollinearity is assessed with the variance inflation factor. A
Poisson model provides incidence rate ratios, and a generalized additive
model tests whether smooth terms improve on the linear specification.

For group comparisons, the province is the unit of inference. Continuous
outcomes are compared on the province-level summaries with Welch t tests
and Wilcoxon rank-sum tests. Isolate-level cluster-robust standard
errors, clustered by province, are reported as a sensitivity analysis.
Resistance rates for the 19 drugs are compared with the same primary and
sensitivity approaches. Holm correction is applied within each family of
related tests.

The figure script draws the two-panel Figure 6 for the temperature and
income groups. The 19 drugs are ordered by the resistance rate in the
reference group, and significance marks follow the primary province-level
Welch tests with Holm correction. Both a 600 dpi PNG and an SVG are
written to `outputs`.

## Notes on interpretation

The analysis is ecological and uses province-level summaries. The
associations reported here describe relationships between regional
characteristics and average ARG abundance and do not establish
individual-level causation.
