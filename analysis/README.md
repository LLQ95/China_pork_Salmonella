# Reproducible provincial ecological analysis

This repository contains the code and data needed to reproduce the
province-level ecological analysis reported in the manuscript on 1,402
non-typhoidal *Salmonella enterica* isolates recovered from retail pork
across 25 Chinese provinces, autonomous regions, and municipalities in
2021.

## Contents

```
.
|-- provincial_ecological_analysis.R   # Main analysis script
|-- README.md
|-- data
|   |-- province_level_data.csv        # 25 provinces, 17 candidate factors
|   `-- isolate_level_data.csv         # 1,402 isolates with group labels
`-- outputs                            # Tables generated by the script
```

`province_level_data.csv` contains one row per province. The response is
the province-level mean number of antimicrobial resistance genes (ARGs),
and the 17 candidate variables cover climate, agricultural production,
pollution, and socioeconomic indicators. `isolate_level_data.csv` contains
one row per isolate, with the serovar, temperature group, income group,
ARG count, IncFIB(K) carriage, and the phenotype for each tested drug.

## How to run

The script uses relative paths and should be run from its own directory:

```sh
Rscript provincial_ecological_analysis.R
```

It was developed and tested with R 4.6.0. The required packages are
`glmnet`, `car`, and `mgcv`, which can be installed with:

```r
install.packages(c("glmnet", "car", "mgcv"))
```

All base functions used for correlation, linear models, two-sample tests,
and proportion tests are part of the standard R distribution. A fixed seed
is set at the start of the script, and cross-validation fold identifiers
are assigned explicitly, so repeated runs produce identical results.

## Analysis steps

The script follows the order of the statistical methods described in the
manuscript. It first calculates Spearman rank correlations between each
candidate factor and provincial ARG abundance. The five factors showing a
significant positive bivariate association then enter the LASSO stage.

LASSO is fitted with `glmnet`, and the penalty is selected through
five-fold cross-validation. A nested leave-one-out cross-validation loop
refits the model after removing each province in turn and records how often
every candidate is retained, which gives the predictor selection
frequency. The final parsimonious model is an ordinary linear model with
temperature and GDP per capita, and the script reports coefficients, 95%
confidence intervals, p values, R-squared, adjusted R-squared, AIC, and
the overall model p value.

Multicollinearity is assessed with the variance inflation factor. A
Poisson model provides incidence rate ratios, and a generalized additive
model tests whether smooth terms improve on the linear specification. The
isolate-level section compares ARG counts between temperature and income
groups, both overall and within each dominant serovar, and compares
resistance rates between groups. Welch t tests and Wilcoxon rank-sum tests
are reported for continuous outcomes, and two-sample proportion tests are
used for resistance rates. Bonferroni correction is applied within each
family of related tests.

## Notes on interpretation

The analysis is ecological and uses province-level summaries. The
associations reported here describe relationships between regional
characteristics and average ARG abundance and do not establish
individual-level causation.
