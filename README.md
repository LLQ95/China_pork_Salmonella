# China retail-pork Salmonella ecological analysis

Code and data for the province-level ecological analysis in the manuscript
describing 1,402 non-typhoidal *Salmonella enterica* isolates from retail
pork across 25 Chinese provinces in 2021.

The reproducible analysis is located in the [`analysis`](analysis)
directory. It contains self-contained R scripts, the input data, and the
reference output tables. See [`analysis/README.md`](analysis/README.md) for
the software requirements and step-by-step instructions.
